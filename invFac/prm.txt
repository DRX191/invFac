Actúa como un desarrollador Senior en React y Supabase. Necesito crear una aplicación PWA de Punto de Venta (POS) "mobile-first".

Stack tecnológico estricto:
- Frontend: React con TypeScript (Vite).
- Backend y BD: Supabase (PostgreSQL y Auth).
- Tablas de datos: AG Grid (Community Edition).
- Lector de código de barras: html5-qrcode.
- Estilos: Tailwind CSS.

Estructura de Base de Datos (Supabase SQL):
1. 'productos': id (uuid), barcode (text, unique), description (text), price (numeric), stock (int).
2. 'ventas': id (uuid), created_at (timestamptz), total_venta (numeric), vendedor_id (uuid).
3. 'venta_detalles': id (uuid), venta_id (uuid fk), producto_id (uuid fk), cantidad (int), subtotal (numeric).

Interfaces TypeScript:
- Product, Sale, SaleDetail.

Pantallas requeridas (.tsx):
1. Pantalla de Ventas (/pos):
- Arriba: Lector de cámara continuo (html5-qrcode).
- Abajo: AG Grid tipado funcionando como carrito.
- Lógica: Al escanear, hacer query a Supabase buscando el 'barcode'. Si existe, agregarlo al AG Grid (o sumar cantidad si ya está).
- Botón "Cobrar": Debe ejecutar una transacción RPC o múltiples inserts en Supabase (primero insertar en 'ventas', obtener el ID, y luego insertar el array en 'venta_detalles').

2. Pantalla de Inventario (/admin/inventory):
- AG Grid cargando la tabla 'productos'. Activar cell editing para actualizar precios/stock directamente en Supabase.
- Formulario simple para crear nuevos productos.

3. Pantalla de Reporte (/admin/reports):
- AG Grid que haga un select a 'ventas' filtrando por el día actual, haciendo un JOIN con 'venta_detalles' para mostrar el desglose.

Genera el código paso a paso: 1) Código SQL para crear las tablas en Supabase, 2) Archivo supabaseClient.ts, 3) El componente PosView.tsx. Usa botones grandes y un rowHeight de 50px en AG Grid.
